# Island Circuit · 起屋遊戲

A playable 2–4 player board game prototype. Choose human or AI captains for every seat.

- [Play online](https://ai-user-cloub.github.io/island-circuit/) (requires GitHub Pages to be enabled)
- [Download the offline game](index.html)
- [Complete rules](起屋遊戲-完整說明書-2026-10-30.md) · [Plain-text rules](起屋遊戲-完整說明書-2026-10-30.txt)

Current fruit magic: Rest costs 1 fruit; Resupply costs 3 fruit and refills oil and warehouse seeds separately to 4 after payment returns to the warehouse; Pause costs 2 fruit; Harvest costs 4 fruit and scores 3 points.

To publish the site, open repository **Settings → Pages**, select **Deploy from a branch**, **main**, and **/(root)**, then save. The playable file is at the repository root as `index.html`.
